# 报告写作（report-writing）

## 骨架
1. **结论**（三行内）：做了什么、结果如何、风险多大。
2. **证据**：命令 + 输出片段 + 时间戳；每条结论可回溯。
3. **复现**：环境、前置条件、步骤编号。
4. **影响**：能拿到什么、影响谁、量级。
5. **修复**：按成本从低到高排序。

## 写法
- 结论先行，不铺垫背景。
- 表格承载对照，正文只写判断。
- 不写「可能存在」——要么验证过，要么标「未验证」并给验证方法。

## 交付
Markdown 主文件 + 附件目录（截图/日志/脚本），文件名带日期与版本。
